# Sponsorship Tracking - Google Sheets Edition

Fuente de datos:
- Google Sheets (QuickBooks exportado por Coefficient)
- Shopify Corro
- Shopify Cavali

Secrets requeridos:
GOOGLE_SHEET_ID
GOOGLE_SERVICE_ACCOUNT_JSON
CORRO_SHOPIFY_STORE
CORRO_SHOPIFY_ACCESS_TOKEN
CAVALI_SHOPIFY_STORE
CAVALI_SHOPIFY_ACCESS_TOKEN

El dashboard carga data/dashboard.json generado por GitHub Actions.
